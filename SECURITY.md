# Security reports

For a suspected security issue, use the current private reporting route described at https://browserpair.com/security or contact support through https://browserpair.com/support.

Do not open a public Issue containing working exploit details, agent keys, browser credentials, cookies, private page observations or personal data. Public Issues are for non-sensitive product and documentation reports.

Include the affected public resource or product version, a concise description, impact and redacted reproduction steps through the private reporting route. Do not test against other people's accounts or data.
